Privacy Policy

Last updated: October 4, 2026

1. Overview

AutoBlogger is a personal automation project operated by its owner. This policy explains what information the application accesses when a Google account is connected for Blogger publishing and how that information is used.

2. Information accessed

When the owner authorizes AutoBlogger through Google OAuth, the application requests the Blogger scope needed to create and manage posts on the owner's Blogger account. The application may receive OAuth authorization data, Blogger API responses, post identifiers, URLs, and related publishing metadata.

AutoBlogger does not request access to Gmail, Google Drive, Google Photos, contacts, or other Google services unless a future version explicitly changes its OAuth permissions and the user grants that access.

3. How information is used

  • authenticate the owner's Blogger account;
  • create and manage Blogger posts requested by the owner;
  • record publishing results, identifiers, and troubleshooting logs; and
  • maintain reliability and idempotency of the publishing workflow.

4. Storage

AutoBlogger is operated locally. Application data and publishing metadata are stored in the owner's local MySQL database. OAuth credentials are stored in the local n8n credential store and are not intentionally published through this website.

5. Sharing

AutoBlogger does not sell or rent Google user data. Data may be transmitted to service providers required for the requested automation, such as Google Blogger for publishing, an AI provider for article generation, and an image provider when an image is requested.

6. Data retention

Logs, article metadata, and publishing records may remain in the owner's local database for operational history and troubleshooting.

7. Security

The application is intended for the owner's local environment. Access to credentials and local infrastructure is protected using the operating system, n8n credential storage, and local configuration controls. No website password or OAuth token should be entered into this public website.

8. Your choices

The owner can revoke Google access from the Google account's security settings or disconnect the OAuth credential from n8n. There is no public user account system.

9. Contact

For questions about this policy or the application, use the developer contact email associated with the Google Cloud project.
