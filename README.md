# AutoBlogger OAuth Site

Static GitHub Pages site for the AutoBlogger Google OAuth application.

## Files
- `index.html` — application homepage
- `privacy.html` — privacy policy
- `terms.html` — terms of service
- `styles.css` — shared styling
- `.nojekyll` — disables Jekyll processing

## Before using with Google Auth Platform

Replace the example domain in your Google Cloud settings with the real domain you control.

For example:
- Homepage: `https://YOUR-DOMAIN/`
- Privacy: `https://YOUR-DOMAIN/privacy.html`
- Terms: `https://YOUR-DOMAIN/terms.html`

For an external production OAuth app, use a domain you own and verify it with Google before adding it as an authorized domain.
