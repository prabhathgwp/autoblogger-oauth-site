AutoBlogger

AutoBlogger is a personal, locally operated automation system that collects news from reputable feeds, generates original article drafts with AI, optionally adds properly attributed licensed imagery, and publishes content to a Blogger site through Google's Blogger API.

How AutoBlogger works

The automation runs through n8n on the owner's computer. MySQL stores application data, provenance, publishing attempts, and system logs. Blogger is the publishing destination.

  • News is collected from selected reputable RSS/Atom sources.
  • Stories are deduplicated and grouped into events before generation.
  • AI is used to produce original editorial content rather than copy source articles.
  • Optional images are obtained from permitted/licensed sources and accompanied by attribution when used.
  • Blogger is accessed through OAuth 2.0 with the Blogger API.

Google user data

Google OAuth is used only to authorize access to the owner's Blogger account for creating and managing Blogger posts. AutoBlogger does not sell Google user data and does not use Google user data for advertising profiling.
